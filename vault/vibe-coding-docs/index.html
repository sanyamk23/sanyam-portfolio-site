4 docs that keep your AI coding agent from losing the plot

AI agents forget everything between sessions. These 4 files are how you give them memory.

01

CLAUDE.md

The rulebook Claude reads at the start of every session.

Where
Repo root. Claude Code loads it automatically.
Put in it
What the project is, the stack, the commands, your always and never rules, and which other docs to read first.
Update when
Your stack, rules, or commands change.

Where the project stands right now.

Bugs, workarounds, and code that looks wrong but is intentional.

Where

Where

Put in it
One entry per decision with an ID, status, date, the reason, and what it replaced.
Update when
You pick a library, a service, or a pattern.
Why it matters
It stops the AI from swapping out your tools or reopening choices you already made.

How to set it up

  1. 1.Create CLAUDE.md at the root and a /docs folder with the other three.
  2. 2.In CLAUDE.md, tell the agent to read progress.md, decisions.md, and known-issues.md before starting work.
  3. 3.End every session with: "Update progress.md, log any new decisions, and add any new gotchas."
  4. 4.Start every new session with: "Read CLAUDE.md and progress.md, then tell me where we left off."
These four docs are for building an app. For an agent that runs jobs for you, use the folder method instead. It also drops the Always and Never sections on purpose, since newer models follow them too literally.
