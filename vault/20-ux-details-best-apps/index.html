20 UX details the best apps use, and the prompt that adds them to yours

Skeleton loaders from Apple, the command menu from Linear, undo toasts from Gmail, Amazon's safe triangle. All twenty from the video, what each one does, plus one prompt that has Claude check your app for every one and build what's missing.

This is the page for anyone who commented UX. The prompt is right below. Copy it, paste it into Claude Code in your project, and it checks your app for all twenty, builds the ones that fit, and gives you the list.
Paste into Claude
Go through the 20 UX details below and check my app against each one. If a detail fits this project and isn't done yet, build it. Skip the ones that don't fit, and the ones that need backend work you can't do from here.

While you build:
- Use what the project already has before you add a library, and match the existing code style.
- Every animation respects reduced motion.
- Build them one at a time, and run the project's checks after each one.

When you're done, list all 20, each marked as one of:
- Built: what you changed, which files, and how I can see it working.
- Already done: where it is.
- Skipped: why.

The 20:

1. Skeleton loaders (Apple). Gray blocks in the shape of the real layout while content loads, made from the same component as the loaded state so nothing jumps. Only show them if loading takes longer than about 300ms.
2. Optimistic updates (React). Small actions like likes, checkboxes and renames update the screen right away and roll back with an error if the request fails (useOptimistic in React 19). Never for payments.
3. Command menu (Linear). Cmd+K or Ctrl+K opens a search of every page and action that works with the keyboard alone. Only in apps people use every day.
4. Shortcut hints (Superhuman). Show each action's keyboard shortcut in menus, tooltips and the command menu, with ⌘ on Mac and Ctrl elsewhere. Shortcuts don't fire while someone is typing in a field.
5. Undo toasts (Gmail). For anything reversible, like delete or archive, drop the confirm dialog. Do it right away and show an Undo toast for 5 to 10 seconds, with a soft delete or a delayed request behind it. The toast has role="status".
6. Stale-while-revalidate (Vercel). Show cached data instantly and refetch in the background, again when the window regains focus or the network comes back. Not for balances, stock counts, or anything where old data costs money.
7. Prerendering (Chrome). Speculation rules with eagerness "moderate" for same site links, leaving out logout and any link that changes data. Check what the router already prefetches first.
8. BlurHash placeholders (Wolt). Store a BlurHash or ThumbHash with each uploaded image and show the blur at the image's exact size while the real one loads.
9. View transitions (Chrome). document.startViewTransition for changes on one page, @view-transition { navigation: auto; } between pages, and the same view-transition-name on elements that move between them. Under 300ms.
10. Swipe-to-dismiss sheets (Apple). Bottom sheets follow the finger and close on distance or a quick flick (presentationDetents in SwiftUI, @gorhom/bottom-sheet in React Native, Vaul on the web). Keep a close button too.
11. Interruptible animations (Apple). Springs that turn around from their current position and speed when interrupted. No CSS keyframes on anything a user can interrupt, and never block input while something animates.
12. Predictive back (Android). Move back handling to OnBackPressedCallback or PredictiveBackHandler so the back swipe can preview the previous screen. It's on by default when targeting Android 16.
13. Hit slop (React Native). Every tap target is at least 44 by 44 points on iOS and 48 by 48 dp on Android, even when the icon is smaller, using hitSlop or padding, without overlapping its neighbors.
14. Safe-area insets (Apple). viewport-fit=cover and env(safe-area-inset-*) on the web, react-native-safe-area-context in React Native, so nothing tappable sits under the notch, the Dynamic Island or the home indicator.
15. One-time-code autofill (Apple). One input with autocomplete="one-time-code" and inputmode="numeric" (textContentType .oneTimeCode on iOS), and the text message ends with a line like "@yourdomain.com #123456".
16. Tabular numbers (CSS). font-variant-numeric: tabular-nums on timers, prices, counters and table columns.
17. Balanced headlines (CSS). text-wrap: balance on headings and short titles, text-wrap: pretty on paragraphs.
18. Continuous corners (Apple). The .continuous corner style in SwiftUI and UIKit. On the web, corner-shape: squircle next to the existing border-radius, which only Chromium browsers draw and everything else ignores.
19. Idempotency keys (Stripe). Make a UUID when the user starts a payment or anything that creates a record, send it as the Idempotency-Key on every retry of that action, and do the same on my own API. Disable the button while the request runs.
20. Safe triangle (Amazon). Hover menus with submenus don't switch while the cursor moves diagonally toward the open submenu (safePolygon in Floating UI, or the menu library's own version).

Run it in Claude Code, Cursor or Codex, opened in your project, so it can read the code and make the changes. A website won't use the Android ones and an app won't use speculation rules, which is why it skips whatever doesn't fit.

Below is what each of the twenty actually is, so you know what Claude just built.

1. Skeleton loaders (Apple)

Gray blocks in the shape of the real layout while it loads, instead of a spinner in the middle of a blank screen. The app feels faster because the page is already there, and nothing jumps when the content lands. Only show it if loading takes longer than about 300ms, or it flashes.

2. Optimistic updates (React)

You tap like and the heart fills in right away, while the request goes out in the background. If it fails, the heart goes back and you get told. React 19 has a hook for this called useOptimistic. Use it for small things that almost always work, never for payments.

3. A command menu (Linear)

Cmd+K opens a search box with every page and action in the app, so nobody has to remember which menu something lives in. Linear made it the standard. Worth it in any app people open every day.

4. Shortcut hints (Superhuman)

When you do something with the mouse, Superhuman shows you the keyboard shortcut for it. People learn the shortcuts just by using the app.

5. Undo toasts (Gmail)

Gmail archives the email the second you click and gives you Undo, instead of asking if you're sure first. Confirm dialogs get clicked through without reading anyway. Undo Send works the same way, it just holds the email for a few seconds before sending.

6. Stale-while-revalidate (Vercel)

Show what you already have cached instantly, fetch the fresh version in the background, and swap it in when it arrives. Vercel's SWR library is named after it. Going back to a screen you just left should never show a spinner.

7. Prerendering (Chrome)

Chrome can load the next page while your mouse is still hovering the link, so by the time you click it's already there. It's one script tag called speculation rules, and browsers that don't support it ignore it.

8. BlurHash placeholders (Wolt)

Wolt made BlurHash, which turns a photo into a string of about 20 to 30 characters that decodes into a blurry version of it. You send that string with the rest of your data and show the blur while the real image loads, so the screen has the right colors from the first frame.

9. View transitions (Chrome)

The browser animates between two pages for you, like a thumbnail growing into the full photo when you tap it. It used to take a whole animation library. Now it's a few lines of CSS, and browsers without it just switch instantly.

10. Swipe-to-dismiss sheets (Apple)

The sheet that slides up from the bottom on iOS, and you drag it back down to close it. It follows your finger, and a quick flick closes it even if you only moved it a little. Vaul does this on the web.

11. Interruptible animations (Apple)

You can grab anything while it's still moving and it turns around from where it is, instead of finishing the animation before it listens to you. Apple's 2018 talk on fluid interfaces is where this comes from. Springs do it, CSS keyframe animations don't.

12. Predictive back (Android)

Start the back swipe on Android and you see a preview of the screen you're going back to, and if you change your mind you just let go. Apps targeting Android 16 get it by default, so if your app overrides the back button the old way, that's the code to move.

13. Hit slop (React Native)

The touch area of a button is bigger than the button you see. A 20 pixel icon still gets a 44 point target, which is Apple's minimum. React Native calls the prop hitSlop, and on the web it's just padding.

14. Safe-area insets (Apple)

The notch, the Dynamic Island and the home bar cover parts of the screen. Safe-area insets tell you how much room to leave, so your bottom tab bar doesn't sit under the home indicator and your header doesn't sit under the island.

15. One-time-code autofill (Apple)

The login code from your text shows up right above the keyboard and fills in with one tap. On a website it's a single attribute on the input, autocomplete="one-time-code". On iOS it's textContentType set to oneTimeCode.

16. Tabular numbers (CSS)

In most fonts a 1 is narrower than an 8, so a timer or a price that changes wiggles side to side. One line of CSS, font-variant-numeric: tabular-nums, makes every digit the same width and the wiggle stops.

17. Balanced headlines (CSS)

text-wrap: balance evens out the lines of a headline so you don't get one lonely word on the last line. text-wrap: pretty does the same for paragraphs.

18. Continuous corners (Apple)

Apple's rounded corners use a smooth curve called a squircle instead of a quarter circle stuck onto a straight edge, which is why iOS icons look softer than everyone else's. It's one setting in SwiftUI, and Chrome can do it on the web now with corner-shape: squircle.

19. Idempotency keys (Stripe)

Someone taps Pay on bad wifi, nothing happens, so they tap it again. With an idempotency key, the retry carries the same ID as the first try, and Stripe returns the first result instead of charging them twice. Use the same idea on your own API for anything that creates something.

20. Safe triangle (Amazon)

On Amazon's old mega menu, you could move your mouse diagonally toward a submenu across the other rows and it wouldn't switch on you. The menu worked out which way you were heading and waited. Floating UI calls it safePolygon, and plenty of menu libraries already have it built in.
