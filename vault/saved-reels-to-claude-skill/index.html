Turn your saved reels into a Claude skill

Claude watches every reel you saved, transcribes it, checks each technique against the official docs and your own projects, and hands you a ranked list of what to do first. Download the skill, install a few tools, paste one prompt.

↓ Download the saved reels skill

What you need

  • Claude CodeRuns the skill. My ten minute setup if you don't have it yet.→
  • PythonRuns the scripts that come with the skill.↗
  • Google ChromeThe window that scrolls your Saved tab and plays each reel.↗
  • ffmpegPulls the audio and the stills out of each reel.↗
  • PlaywrightLets the skill drive that Chrome window.↗
  • WhisperTranscribes every reel on your own computer.↗
  • yt-dlpThe backup for reels the browser won't let it record.↗

Install it

Download the skill with the button at the top, install Python and Chrome, then run the lines for your computer. Close and reopen the terminal afterward so it finds ffmpeg.

Mac:

Copy and paste
mkdir -p ~/.claude/skills
unzip ~/Downloads/saved-reels-to-skill.skill -d ~/.claude/skills
pip3 install playwright openai-whisper yt-dlp
brew install ffmpeg

Windows, in PowerShell:

Copy and paste
New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
tar -xf "$HOME\Downloads\saved-reels-to-skill.skill" -C "$HOME\.claude\skills"
pip install playwright openai-whisper yt-dlp
winget install ffmpeg

Run it

Open Claude Code in the project you want the plan for and paste this.

Start the run
/saved-reels-to-skill My Instagram username is [username]. Make the plan for this repo, and tell me what fits my other projects too. Skip my own posts, start the board so I can watch, and show me the ranked plan before you change anything.

Chrome opens in its own window. The first time, you log in to Instagram there yourself, and Claude never sees your password. Reels play at normal speed, 25 a batch at about two minutes each.

What it does

  1. 1.Scrolls your Saved tab and collects every post. It leaves out your own posts, and anything that plainly isn't a technique, like memes, once you OK the list.
  2. 2.Plays every reel with the sound on, transcribes it with Whisper, and saves a still each time the screen changes, so Claude reads the code exactly as it was on screen.
  3. 3.Cuts the fluff, flags reels that keep their steps behind "comment GUIDE", and merges a trick six creators posted into one version with the best details from each.
  4. 4.Checks everything it keeps against the official docs, and runs code, commands, and config in a sandbox folder when it can.
  5. 5.Reads how you work, like your stack, CLAUDE.md, hooks, skills, recent commits, and other projects, then puts each technique where it belongs: this project, another one of yours, or a library for later.
  6. 6.Hands you a plan you can read in two minutes, with three to seven things to do first, why each one matters for you, how long it takes, and which reels it came from. Say "do 1 to 3" and it builds them.

Watch it work

The board opens at localhost:4321 next to the Chrome window. It shows the reel Claude is on, the stills, what the creator said, what Claude made of it, and the techniques ranking themselves as it goes.

Instagram's terms don't allow automated access, and a script opening your reels counts, even at normal speed. It's your account and your call.
