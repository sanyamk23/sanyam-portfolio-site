Craft Anything: rebuild any website or app from what you can see

The free, open source tool from the video. You give it a website, an app or a game, it studies what a visitor can see, Claude Code builds your own version, and then it checks the copy against the original. A one prompt install, how to run your first build, and the fixes for the two bugs people keep hitting.

Get Craft Anything on GitHub ↗
This is the page for anyone who commented REPO on the Craft Anything video. Only download it from github.com/storytold/craft-anything. It's early alpha, with three releases in three days, so if a step here doesn't match what you see, the README wins.

What it does

REA looks inside an app's code to work out how it works. Craft Anything can start from the outside instead. In Clean room mode, which is the default, nothing inside the original is read: not its code, its files or its page source. It works from what you'd see as a visitor, so screenshots, the visible text, the measured layout, colors, fonts and spacing, and the menus opened up. Then Claude Code builds your version from scratch.

The part REA doesn't have is the check at the end. Every build gets compared with the original (a website at three screen widths, an app by running it, a game by its own self test), and it keeps refining until the two are close. Each check says how alike they are and lists what doesn't match yet.

Install it

You need Claude Code installed and signed in. Craft Anything runs your own claude program on your own login, so it never sees your account. Then paste this into Claude Code. It finds the right download for your computer, checks it, and runs the doctor before you open the app.

Install Craft Anything
Install Craft Anything for me. The only official source is https://github.com/storytold/craft-anything, so don't use any other copy or mirror.

1. Check that Claude Code is installed and signed in (`claude --version`). If it isn't signed in, tell me to run `claude auth login` and stop.
2. Open the latest release on that repo's Releases page and pick the desktop app for my OS and CPU, using the file names listed in the README's Downloads section (the .msi for Windows, the universal .dmg for macOS, the AppImage, .deb or .rpm for Linux). Tell me which file you picked and why before you download it.
3. Check the file against SHA256SUMS.txt from the same release. If the checksum doesn't match, delete it and stop.
4. Install it, then make sure `craft-anything-cli` is on my PATH and run `craft-anything-cli doctor` (if the app didn't put the CLI on my PATH, follow the README). Show me what it reports and fix only what it says is missing, asking me before you install anything else.
5. If there's no desktop build for my system, show me the build-from-source steps in the README (they need Rust 1.97 or newer) and wait for my OK.

If you'd rather do it by hand: download the app for your system from the Releases page, install it, and run this in a terminal. It checks the install, your coding agent and the engines, and tells you what's missing.

Copy and paste
craft-anything-cli doctor

Claude Code is the agent it supports first. A Codex adapter exists but the README says it hasn't been tested on a real install yet, and GitHub Copilot works through its own CLI with a separate login.

Your first build

  1. 1.Open the app. It asks what you want to make. Pick a website, an app or a game.
  2. 2.Type the address, or pick the app. Start with a site of your own, it's the easiest way to see how close it gets.
  3. 3.Leave Clean room on.
  4. 4.Say what you want, in plain words. "Recreate this website" works, and so does "Build me a PDF editor that looks and works like this app."
  5. 5.Press Start and watch the four steps: Study, Build, Check, Ready. It may stop to ask you something, and it asks before it runs a new kind of command. Answer and it keeps going.
  6. 6.At Ready you can open the result or its folder. Anything you want changed, type it in the box at the bottom and it refines the build.

Clean room or Deep

ModeWhat it readsUse it for
Clean room (default)Only what you can see: pictures you add, the site as a visitor sees it, and a picture of an app's window if you allow it. Tools that would look inside get refused.Most builds, and anything that isn't yours.
DeepEverything. A program's code and files, a website's JavaScript, and Ghidra if you have it installed.Your own software, for your private use.

You switch modes in the title bar or in Settings. Clean room is a rule about which tools Craft Anything will use. It doesn't sandbox your computer, and installing a build's dependencies runs code like any other project, so only click always allow for projects you trust.

If it breaks

  • "No conversation found with session ID" (issue #478, on v0.3.0). The build is trying to resume a session that doesn't exist. Close the app, back up the project's craft.json, delete its agent_session line, and start again. The fix was merged on the repo after v0.3.0 came out.
  • "Available MCP tools: none" (issue #64). Claude Code started without Craft Anything's tools. Update to the latest release and run craft-anything-cli doctor. The issue is still open, so check it for a newer workaround if that doesn't do it.
  • Claude Code stops the build. Switch to Clean room, and describe what you want built instead of naming a brand you want copied.
Use it on software you own or are allowed to examine. It never gets past DRM, logins or anti-cheat, and it's told not to copy logos, photos or text unless you confirm you own them or have permission. So your build gets the layout and the behavior, and you bring your own name and art.
