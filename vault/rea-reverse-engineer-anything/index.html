REA: reverse engineer any feature from any app

REA lets Claude Code look inside an app you don't have the code for, work out how a feature you like actually works, and build your own version of it. Free and open source. Repo up top, a one prompt install, then how to use it.

Get REA on GitHub ↗
Only install REA from github.com/morluto/rea, rea.tools, or the rea-agents package on npm. Copies with similar names are going around, and at least one fake has been reported as a trojan.

Install it

You need Node.js 22.19 or newer and an agent like Claude Code, Codex or Cursor. Open Claude Code anywhere and paste this. It checks Node, shows you what setup will change, and waits for your OK before it touches anything.

Install REA
Install REA for me. The official repo is https://github.com/morluto/rea and the npm package is rea-agents, so don't use any other copy. First check that I have Node.js 22.19 or newer, and tell me how to update it if I don't. Then run npx -y rea-agents@latest setup --client claude_code --dry-run and walk me through what it wants to change. Once I say OK, run the same command with --yes in place of --dry-run, then tell me to restart Claude Code.

On Codex or Cursor, swap claude_code for codex or cursor. If you'd rather do it yourself, run this in a terminal, pick your agent from the list, approve the changes, and restart the agent.

Copy and paste
npx rea-agents setup

After the restart, type /mcp in Claude Code. If rea is in the list, you're set.

Use it

Find a feature you like in an app on your computer, then tell Claude which app and which feature. Fill in the brackets.

Reverse engineer a feature
Use REA to figure out how [feature] works in [app]. Show me the evidence behind each thing you find, and tell me what you couldn't confirm. Then plan a version of it for this project and wait for my OK before you build anything.

Claude opens the app through REA, traces the code behind that feature, and gets back what it found along with the proof and the gaps. Then it explains the feature in plain English and builds your version once you say go. Everything gets analyzed on your own machine. The only thing that leaves is what Claude reads, same as any other session.

What it can open

  • Electron and JavaScript apps, like Notion. Nothing extra to install. Start here, it's the easiest.
  • Websites. Needs Chrome. REA reads the page, the scripts and the network calls.
  • .NET apps. Nothing extra.
  • Android apps. Needs JADX and a JDK.
  • Native Mac and Windows apps. Needs Hopper, Ghidra or IDA. Setup can install Hopper for you if you approve it.

REA updates often, and most releases fix bugs. Run npx rea-agents@latest setup every so often to stay current, then restart your agent.

Use it on software you own or are allowed to examine. Paid tools like IDA and Hopper need a real license, and REA doesn't give you one.
